# 看板显示与统计

普通看板使用 `/dashboard`，大屏入口使用 `/dashboard?screen=1`。任务数据仍由飞书提供，以下操作仅调整查看方式。

## 空完成状态与异常提示

- “完成状态/完成情况”为空的任务按未完成展示，卡片及详情标注状态未填写，顶部提示总数；即使已填分值或完成时间，也不计完成数与积分。有截止时间的任务仍按实际时间判断是否逾期。
- 非空且无法识别的状态暂不纳入任务及积分统计，正常任务继续显示。顶部“查看异常任务”打开清单，展示对应任务名及原状态；打开时与其他抽屉一样暂停轮播及三个列表自动滚动，关闭后恢复。
- 补填状态后随下一次同步重新归类及计分。所有任务均为非空未知状态时明确报错并提供清单，不显示空任务成功；网站不回写飞书。

## 任务详情

- 点击任务标题或卡片空白区域打开详情抽屉。
- 详情完整显示标题、备注、执行人、发布人、部门、分值、截止时间和已记录的完成时间，支持换行与纵向滚动。
- 手机（宽度不超过760px）使用圆角底部面板，高度随内容变化、最高占视口84%，顶部保留背景；桌面保留右侧抽屉。关闭操作在内容滚动时保持可见。
- 打开详情或完成趋势时固定背景位置，面板内可滚动；滑动遮罩或滑到面板边缘不会带动下面的任务，关闭后恢复原浏览位置。
- 头像和姓名继续按已有成员档案匹配；有档案时可进入介绍并优先显示档案照片，缺图或加载失败显示圆形队徽；没有档案时用圆形队徽且仅展示。
- 点击关闭、抽屉外的遮罩或按 Esc 关闭；Tab 和 Shift+Tab 在抽屉内循环，关闭后恢复页面滚动。任务同步变化时详情更新，任务被移除或看板锁定时关闭详情。

## 大屏与浏览器全屏

- “大屏模式”切换网页布局并隐藏全站导航、页脚；桌面宽至少1200px、高至少700px，时使用固定视口内的分页轮播。宽至少1000px时，即使普通模式或无法固定高度，也按实际宽度、字号及视口高度预算手动分页；宽不足1000px的手机和平板完整展示当前筛选结果，连续向下滚动。
- “浏览器全屏”在点击后调用浏览器原生全屏，同时开启大屏布局；可点击“退出全屏”或使用浏览器的 Esc 操作退出。退出浏览器全屏后仍可保留大屏布局，两个按钮各控制对应状态。
- 浏览器不支持或不允许全屏时，显示提示并保留可用的大屏布局；不会因为全屏失败而中断任务读取。刷新后不会自动请求浏览器全屏，需要再次点击。

## 任务倒计时与临近截止

- 已完成任务和未设置截止时间的任务不显示临近截止标签。
- 未完成任务到达截止时间后显示“已逾期”；未逾期且与当前时间属于同一个北京时间自然日时显示“今日到期”；跨日但剩余不超过24小时显示“24小时内”；其余不超过72小时显示“3天内”。
- 标签按浏览器当前时间每秒更新，不使用闪烁或弹窗提醒，不影响飞书原有通知。
- 删除顶部独立“距离最近截止”行；每张任务卡底部左侧同时显示秒级倒计时与北京时间截止日期，发布人继续保留。未到期为“剩余 3天 06:24:18”，到期后为“已逾期 …”，未设日期显示“未设置截止”。已完成卡片显示完成时间，并保留截止时间。
- 全部卡片沿用页面唯一每秒时钟，不给单卡创建计时器或按秒请求接口；后台暂停时钟更新，返回前台按当前绝对时间立即校准。日期文本单独缓存，时间数字等宽，秒数变化不会使内容宽度跳动。
- 大屏任务分页仍每15秒切换。页面隐藏或详情/统计抽屉打开时暂停切换，不影响自动同步。

## 赛事倒计时

- 两场赛事位于标题左右，横向卡片区域等宽且与标题等距，左卡信息在外/时间在内，右卡左右镜像；窄屏在标题下并排或上下排列。时分秒继续自动更新，不再独占任务上方卡片行。
- 赛事独立于任务筛选。当前显示“2027RMUL最终形态”和“2027RMUC最终形态”，分别以北京时间2027-01-04 00:00及2027-03-08 00:00为目标，标注“最终形态目标”；配置和日期口径见[赛事倒计时配置](赛事倒计时配置.md)。

## 显示偏好

- 浏览器只保存组别、任务状态、大屏布局、轮播开关四项偏好，刷新或重新打开后恢复。地址中显式传入 `screen=1` 或 `screen=0` 时优先采用该值。
- 搜索内容、访问口令、人员信息和任务数据均不写入localStorage或sessionStorage。保存显示偏好不等于保存登录状态，刷新后仍需按原有规则解锁。
- 点击“重置显示”恢复全部组别、未完成状态、普通布局和开启轮播，并清空当前搜索。旧组别已经不存在时自动回到全部组别。
- 浏览器禁止保存设置时，页面继续工作并提示设置仅本次有效。

## 完成趋势

1. 点击“已完成”统计卡片中的“完成趋势”，打开独立统计抽屉，不占用大屏主任务区域。
2. 统计跟随当前组别和关键词筛选，不跟随未完成/已逾期/已完成标签。按任务计数，同一多人任务只算一项；与按已完成任务分值及执行人计算的个人总分榜口径不同。
3. “本周完成”从北京时间周一00:00开始；“近7天”包含今天和前6个北京时间自然日。任务必须为已完成且具有不晚于当前时间的有效完成时间，才纳入日期统计。
4. “本周按时完成率”仅使用本周已完成、同时记录完成时间和截止时间的任务；完成时间不晚于截止时间视为按时。没有可比较任务时显示“—”，不编造百分比。抽屉显示实际参与计算的任务数。
5. 部分已完成任务缺少有效完成时间时，显示未纳入统计的数量。全部已完成任务都没有有效完成时间时显示“暂无完成时间记录”，不展示误导性的零值趋势；确实没有已完成任务时可以显示零值。
6. 当前真实任务表没有完成时间列，因此这部分功能会显示上述缺失提示。要产生真实趋势，需要在原表记录真实完成时间；网站默认读取名为“完成时间”的日期时间字段。若实际列名不同，可在EO的 `FEISHU_FIELD_MAP` 中增加 `completedAt` 映射，保留已有其它映射。
7. 由表格管理员维护完成流程，在任务真正完成时写入当次实际时间，重新完成时更新该值。历史任务仅补录能够确认的实际日期，不批量填成今天，也不以任务发布时间、截止时间或网站首次读取时间代替完成时间。
8. 默认字段新增真实值后可随既有接口自动读取；若修改EO字段映射，需要按平台要求重新部署。此功能不额外申请写权限，也没有让网站修改任务或自动化。本次开发没有更改现有表格。

## GitCode 研发动态

- 配置GitCode仓库后显示代码贡献榜、最近更新与仓库同步状态；未配置时隐藏。按提交次数统计，与飞书的个人总分榜分开。
- 支持作者与队员对应、已有成员头像和个人页；各仓库及贡献/动态分别缓存，失败时保留可用项并提示更新中断。组织及逐仓同步详情默认收起，可在标题栏展开，不隐藏异常提示。
- 配置、人员映射与统计范围见[GitCode研发动态接入](GitCode研发动态接入.md)。

开发与验证记录见[看板开发实录](看板开发实录.md)。

## 紧凑工具栏

搜索与组别同排，待办/逾期/完成使用横向数字指标，桌面尽量同一行、手机紧凑换行；不影响完整筛选或完成趋势。任务倒计时与截止时间放在每张卡片底部，删除独立最近截止窄条。顶部队徽、队名、标题、时间与全部按钮保留，压缩留白和排列。

两场赛事倒计时在宽屏位于“任务看板”标题左右，手机在标题下并排展示，任务区域不再另占赛事卡片行。“最终形态目标”标记保持可见，日期按北京时间显示，悬停日期可查看含年份的完整时间。配置仍在 `app/data/competitions.ts`。

分页任务卡按窗口宽高和字号确定固定行数及容量，同一窗口完整页始终保持相同行数；标题最多两行，备注和多人员通过详情/+N入口查看完整内容。只有尾页允许不足项，翻页保持任务面板高度和研发区位置稳定。手机连续滚动保留完整人员。桌面大屏赛事字号根据卡片实际宽度提高，普通模式保持原有比例。

宽裕的大屏赛事分为三列：名称独立在外侧，参考说明与北京时间居中，天数/时分秒横向靠内；左卡“时分秒 天数”、右卡“天数 时分秒”，两侧天数均朝向任务看板标题。1800–2199px桌面将名称与参考信息合并为一组，以两列镜像排列，保证赛事标题宽度；1200–1799px桌面同样保持标题两侧，较窄卡片只在框内调整信息行；普通模式保持原有排布。

固定大屏优先容纳完整任务行；不足一整行的高度交给下方研发动态，任务分页保持固定位置，不随各页文字长短移动。研发贡献榜与最近更新在各自区域内自动滚动，按钮分别暂停/继续。未启用研发动态时保留原任务区域分配。顶部两场赛事使用等宽列并拉伸到相同高度，内部名称、元信息和时间继续镜像。

三个列表（个人总分榜、代码贡献、最近更新）都保留完整条目，桌面超出可视区域后约22px/秒纵向滚动，首尾停留后循环；没有溢出时显示“无需滚动”。鼠标悬停或键盘焦点进入列表时临时停住；手动滚动会暂停该列表，可用标题按钮恢复。抽屉打开及后台标签暂停，手机默认不自动滚屏。1080p优先容纳两行任务；桌面大屏按当前窗口宽高和字号重算固定页容量，空间不足时减少固定行数，列表在各自区域滚动；普通模式和手机仍完整向下滚动。

## 个人总分榜

- 原右侧待办与完成任务数量榜合并为一张个人总分榜，大屏占用原两块榜单的整体高度。每行显示圆形头像、姓名、总分和已完成任务数；有任务的执行人均参与，尚无积分显示0分。
- 仅已完成任务的有效分值计入执行人总分，不要求完成时间；未完成及逾期未完成不产生积分。发布人不因此得分。多人任务每位执行人各得完整分值，同一任务及人员标识去重，同名不同标识不合并。
- 分值支持非负数字及数字单选，0分合法；空白显示“未设分”，异常显示“分值异常”，两者均不计分。已完成任务缺分、异常或未分配负责人时提示对应数量，不以旧优先级推算分数。完成任务数包含缺分任务，因此并非计分任务数。
- 每次读取当前记录重新汇总，不累计网页刷新次数。撤回完成会撤回积分；修改分值、补分、转交负责人或删除记录随下次成功同步重新计算。历史已完成任务补填分值后也纳入；任务被删后不保留历史积分账本。读取中断时沿用已有中断提示，不将旧结果当作最新积分。
- 按总分降序，同分并列，姓名和人员标识用于稳定排列；榜单范围为当前接口返回的全部记录或所选组别，不受任务列表的关键词、状态和分页影响，无额外周/月限制。
- 保留现有成员资料头像及个人页入口，无档案人员仅展示。个人总分榜、代码贡献榜和最近更新各自滚动与暂停，悬停、键盘阅读、抽屉和后台暂停，手机默认静止。
- 卡片与详情使用分值标签；任务列表以截止时间优先，同截止时分值高者优先，零分先于缺分；已完成列表仍按真实完成时间倒序。固定容量分页规则不变。

用户确认的2K尺寸为2560×1600。桌面大屏使用动态视口高度，倒计时、中央标题在同一头部行，短屏收紧操作区和分页控件占高，不通过裁掉任务日期或倒计时来塞入视口。系统或浏览器缩放按实际CSS视口重算容量，同一视口每页行数固定。
