# 燕鹰网站视觉规范

2026-10-20 按用户要求，布局与风格均恢复为视觉改版前的版本，不再自行调整设计。

- 首页、导航、页脚、横幅、成员与成果卡片保留原布局；配色、字体、字重、阴影、渐变、轮播高亮和响应式样式恢复原值。
- CSS 以视觉改版前的 `2c5bbfd` 为基准；成果页样式采用同版式的原 RC 卡片样式，不包含已取消的来源说明样式。
- Wiki 展开列表的“首页”入口保留；现有章节、搜索和作者功能保留。
- 成果页保留 RoboMaster 年度奖项数据和简洁展示，不恢复来源链接、公告、核实说明、队名或脚注。
- 后续修改功能时保持现有风格与布局，除非用户明确提出新的视觉要求。
