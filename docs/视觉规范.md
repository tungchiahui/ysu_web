# 燕鹰网站视觉规范

本轮重构于 2026-10-20，将燕鹰的版式与迁移来源网站区分开来。网站继续使用 Nuxt 和现有内容仓库，由 EO Pages 构建发布。

- 主色为深海军蓝，铜橙用于强调和交互，暖白用于浅色背景；深色主题使用蓝灰背景与浅铜橙。颜色统一在 `app/assets/css/tokens.css` 定义，组件不再硬编码旧蓝青色。
- 首页采用文字与独立影像分栏，展示战队名称、介绍、招新和 Wiki 入口；战队影像保留 RoboMaster 来源，并提供播放暂停按钮。偏好减少动态效果时停止视频和轮播自动播放。
- 导航采用文字下划线与移动端编号菜单；960 像素以下折叠菜单，Escape 可关闭并将焦点返回菜单按钮。保留主题切换、当前栏目状态和跳转正文入口。
- 首页精选轮播采用图文分栏，原有切换、暂停、触摸滑动、焦点暂停功能保留。首页栏目改为桌面三列、平板两列、手机单列的图文网格。
- 内页使用浅底标题区、右侧照片与角部标记；手机隐藏装饰照片，保留标题和正文。成员卡片改为照片、姓名与横线信息行；成果页改为年度列表，保留全部官方来源；Wiki 使用同一色板及清晰的正文层级。
- 静态界面标题使用本地 Noto Serif SC 700 汉字子集（约 87 KiB），从内容仓库 `public/fonts/` 同步；许可同目录保留。动态文章标题、成员姓名及正文采用系统字体，以覆盖持续增长的字库。
- CSS 按公共组件及页面维护，断点分别位于对应样式文件和 `responsive.css`。新增组件遵守主题变量，确保深浅主题与 320 像素以上手机视口可用。
