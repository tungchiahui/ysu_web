1. 向用户说明具体范围：新建“燕鹰官网任务看板”，仅申请记录/字段读取权限，限定现有多维表格，密钥只配置到 EO 私有函数环境；不申请任务写权限，不改表格或自动化，不发送消息。
2. 用户明确回复“同意按上述范围创建和配置”后才开始变更。
3. 在开发者后台点击“创建企业自建应用”。
4. 应用名称填写“燕鹰官网任务看板”。
5. 应用描述填写“供燕鹰战队官网读取现有任务多维表格并展示，只读访问，不编辑任务或发送消息。”保留默认图标。
6. 点击“创建”。结果进入新应用，状态“待上线”。未添加机器人、网页应用或消息能力。
7. 点击左侧“权限管理” → “开通权限”，保持“应用身份权限 tenant_access_token”标签。
8. 搜索 `base:record:retrieve`，结果为“根据条件搜索记录”，关联 API 为“列出记录”“查询记录”；勾选该条。
9. 在同一个弹窗中改搜 `base:field:read`，结果为“获取字段信息”，关联 API 为“列出字段”；勾选该条。
10. 确认弹窗“应用身份权限(2)”后，点击“确认开通权限”。返回权限管理，看到两项权限均为“已开通”，均是应用身份，无用户身份权限。
11. 点击“创建版本”。初次查看版本表单时“权限变更”为“暂无”，因此先返回权限管理核实实际保存结果，未误认为权限没有开通；免审权限已显示“已开通”。点击权限升级介绍“我知道了”。

13. 可用范围保留“部分成员”，仅当前应用所有者；不添加机器人，不开启对外共享，也未扩大到全员。

15. 进入表格“分享”，搜索应用名，显示“未能找到相关结果”。没有邀请其他成员。
16. 关闭分享，点击文档右上角“…”更多菜单；当前账号菜单中没有“添加文档应用”入口。未通过修改现有权限或接管文档来绕过。

12. 本次两项真实读取均成功，未额外给应用添加文档可管理权限或其它协作者权限。官方文档另列高级权限场景的配置要求；本次不为尚未发生的错误扩大权限。
